# 03. Site architecture

One domain. Suggested routes:
```
/                         Solvern Home (main site, hub)            not designed yet
/[trade]                  23 trade pages, e.g. /carpentry, /hvac  3 designed
/customer-service         Request a callback (customer service hub) designed
/concept-preview          Standalone Concept Preview flow (optional; the form also lives on each trade page)
/projects/[type]          Kitchen, bathroom, basement, additions, whole-home, outdoor living  later
/areas/[neighborhood]     Buckhead, Alpharetta, Decatur, Marietta and more                 later
/reviews, /financing, /about, /privacy, /terms
```

## Navigation rules (owner decision)
- **The main site links to every trade.** The full 23-trade directory, grouped by the six families, appears **only on the main site** (in its menu and footer).
- **Trade pages do not loop out.** No "All trades" menu and no trade directory on trade pages. A trade page header has: logo, Services, Our team, Reviews, Financing, a quiet "Customer service" link, the phone number and one primary button.
- **Customer service is quiet.** Reached from the header text link and the footer "Help" column, not from a big section.
