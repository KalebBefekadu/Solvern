# Solvern website

Handoff package for building the Solvern Home website in Claude Code.

## Start
1. Unzip this folder to `~/Desktop/Projects/solvern`.
2. Open a terminal in that folder and run `claude`, or open the folder in the Claude Code desktop app.
3. First prompt: "Read CLAUDE.md and the docs it lists, summarize the plan back to me, then start Phase 1 of docs/07-build-plan.md."

## Contents
- `CLAUDE.md`: rules and reading order for the agent.
- `docs/`: brief, v2 design, architecture, page specs, features, tech plan, build plan, open items, history, full v1 brand kit.
- `docs/content/`: data for all 23 trades and approved copy for three pages.
- `design/reference-pages/`: static HTML exports of the approved designs (open in a browser).
- `design/brainstorm-tools/`: tool illustration drafts, exploration only.
- `tokens/`: v2 CSS tokens and the v1 token file.
- `assets/`: logos and the illustration placeholder.
